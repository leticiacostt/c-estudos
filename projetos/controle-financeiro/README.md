# 💰 Sistema de Controle Financeiro em C

Projeto desenvolvido em linguagem C como parte dos meus estudos de lógica de programação e desenvolvimento de software.

O sistema permite registrar recebimentos e despesas, consultar o saldo, visualizar o extrato das movimentações e realizar o cálculo do Imposto de Renda da Pessoa Física (IRPF).

A proposta foi transformar os conceitos estudados durante o curso em uma aplicação prática, trabalhando com entradas de dados, operações matemáticas, estruturas de repetição, condições e organização das informações.

## ⚙️ Funcionalidades

- **Registro de recebimentos:** permite registrar valores recebidos.
- **Registro de despesas:** permite adicionar despesas ao controle financeiro.
- **Consulta de saldo:** calcula o saldo a partir dos recebimentos e das despesas registradas.
- **Extrato financeiro:** apresenta as movimentações financeiras registradas.
- **Cálculo de IRPF:** realiza o cálculo do imposto conforme as regras implementadas no programa.
