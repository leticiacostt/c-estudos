# 💻 Estudos de C

Repositório criado para reunir exercícios e projetos desenvolvidos durante meus estudos da linguagem **C**, registrando na prática os conhecimentos adquiridos ao longo do curso *Learning to Program*, da FIAP.

Minha jornada na programação começou anteriormente com Python e se expandiu para C, fortalecendo minha base em lógica de programação, resolução de problemas e desenvolvimento de aplicações.

---

## 📚 Conteúdos estudados

Durante o curso, estudei e pratiquei os seguintes conceitos:

- Variáveis, tipos de dados e constantes;
- Entrada e saída de dados com `printf` e `scanf`;
- Operadores aritméticos, relacionais e lógicos;
- Estruturas condicionais: `if`, `else if`, `else` e `switch`;
- Estruturas de repetição: `while` e `for`;
- Contadores e acumuladores;
- Operações matemáticas e comparações;
- Matrizes, vetores, funções e ponteiros;
- Algoritmos de ordenação;
- Compilação e execução de programas em C.

---

## 🧩 Exercícios

Os exercícios deste repositório foram desenvolvidos para consolidar os fundamentos da linguagem C e aplicar os conceitos estudados na resolução de problemas.

Entre os temas praticados:

- Operações matemáticas, médias e cálculos de áreas;
- Antecessor, sucessor e comparação entre números;
- Verificação de maioridade e aprovação;
- Identificação de números positivos, negativos, pares e ímpares;
- Controle de acesso e aplicação de descontos;
- Menus utilizando `switch`;
- Estruturas de repetição, contadores e acumuladores;
- Tabuada, múltiplos e números divisíveis;
- Soma e contagem de valores em intervalos;
- Exercícios com matrizes, vetores, funções e ponteiros;
- Algoritmos de ordenação.

---

## 🚀 Projetos

Além dos exercícios, este repositório reúne projetos práticos desenvolvidos durante o aprendizado.

### 💵 Projeto 1 — Cálculo de IRPF

Programa desenvolvido em C para praticar a lógica de cálculo do Imposto de Renda da Pessoa Física (IRPF).

### 💰 Projeto 2 — Sistema de Controle Financeiro

Sistema desenvolvido em C com funcionalidades para registrar recebimentos e despesas, consultar o saldo, visualizar o extrato financeiro e calcular o IRPF.

O projeto reúne diferentes conceitos de programação em uma aplicação prática, permitindo exercitar a lógica, as operações matemáticas e a organização do código.

Consolidar os fundamentos da linguagem C por meio de exercícios e projetos práticos, desenvolvendo o raciocínio lógico e a capacidade de transformar conceitos de programação em soluções funcionais.

Este repositório registra minha evolução, desde os primeiros exercícios até o desenvolvimento de aplicações mais completas.
